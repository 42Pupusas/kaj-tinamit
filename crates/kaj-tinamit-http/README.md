# kaj-tinamit-http

Blocking HTTP transport used by [`kaj-tinamit-client`](https://crates.io/crates/kaj-tinamit-client) for the GitLab REST API. It provides the rustls-backed transport layer without requiring an async runtime.

This crate is normally used through `kaj-tinamit-client`.
